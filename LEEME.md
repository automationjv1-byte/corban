## Qué hay en esta carpeta

| Carpeta | Qué es | ¿Se sube al hosting? |
|---|---|---|
| `sitio/` | El sitio completo (incluye `.htaccess` para Hostinger y `_headers` para Netlify) | **Sí: es lo único que se sube** |
| `apps-script/Codigo.gs` | El código del script. Se pega en la planilla (Extensiones → Apps Script) | No |
| `pruebas/` | Pruebas automáticas, para quien modifique el código. Abrir con un servidor local y la pestaña a la vista | No |
| `Archivo/` | Versiones anteriores de las guías | No |
